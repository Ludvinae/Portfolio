Yorksoft

Application de suivi de tickets de support, réalisée pour le titre de Concepteur Développeur d'Applications. Un client signale un incident sur un logiciel ; l'équipe support le qualifie, l'assigne, le traite et le clôture, avec calcul automatique de la priorité et suivi des délais (SLA).

  • Cycle de vie complet du ticket, tableaux de bord par rôle (administrateur, directeur, manager, technicien)
  • Authentification JWT avec cinq profils, base de connaissances, historique des actions
  • Déployée sur un VPS : Docker Compose, HTTPS par Caddy, CI/CD GitHub Actions

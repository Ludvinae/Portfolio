# Portfolio

Source of [benoitchamplon.fr](https://benoitchamplon.fr): plain HTML and CSS, no build step, published by GitHub Pages from the `main` branch.

- `index.html`: home page
- `mentions-legales.html`: legal notice
- `style.css`: shared stylesheet (light and dark themes follow the system setting)
- `CNAME`: the custom domain GitHub Pages serves
- `.nojekyll`: tells GitHub Pages to serve the files as is, without Jekyll

Preview locally by opening `index.html` in a browser, or with `python -m http.server` in this folder.
